## Run Locally

No build step is needed.

```bash
git clone https://github.com/Gouthamideraje24/portfolio.git
cd portfolio
```

Then open `index.html` in your browser, or use the **Live Server** extension in VS Code.

## Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. Your site will be live at `https://gouthamideraje24.github.io/<repo-name>/` after a minute or two.
